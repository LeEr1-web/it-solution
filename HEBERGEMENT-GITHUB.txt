METTRE LE SITE EN LIGNE GRATUITEMENT AVEC GITHUB PAGES (≈ 10 minutes)

Le site n'a besoin d'aucun serveur : GitHub Pages l'héberge gratuitement, en HTTPS.
La réception des demandes (email / Google) et la page de gestion fonctionnent pareil.

FICHIERS À METTRE EN LIGNE
  index.html  app.js  data.js  style.css
  services.html  services.js
  fiche-tarifs.html  fiche-tarifs.js  fiche-tarifs.css
  gestion.html  gestion.js  gestion.css
  prospection.html  prospection.js  prospection.css  osm-martinique.json  img/
  mentions-legales.html  confidentialite.html
  ⚠ NE METTEZ PAS EN LIGNE google-apps-script.gs : il contient votre code de gestion
    (CLE_GESTION). Il reste sur votre ordinateur et se colle dans Google Apps Script.

MÉTHODE SIMPLE (sans rien installer)
  1. Créez un compte sur https://github.com (gratuit).
  2. Bouton « + » en haut à droite > « New repository ».
     Nom : it-solution — Public — « Create repository ».
  3. Cliquez « uploading an existing file », glissez les fichiers listés ci-dessus,
     puis « Commit changes ».
  4. Onglet « Settings » > « Pages » > Source : « Deploy from a branch »,
     branche « main », dossier « / (root) » > Save.
  5. Après 1 à 2 minutes, l'adresse apparaît :  https://VOTRE-COMPTE.github.io/it-solution/
     Copiez-la dans google-apps-script.gs (REGLAGES.SITE_URL) si vous utilisez Google.

MÉTHODE AVEC GIT (le dossier est déjà prêt : dépôt git initialisé)
  Après l'étape 2 ci-dessus, dans ce dossier :
    git remote add origin https://github.com/VOTRE-COMPTE/it-solution.git
    git push -u origin main
  Puis l'étape 4. Pour publier une modification ensuite :
    git add -A && git commit -m "Mise à jour des prix" && git push

MODIFIER UN PRIX OU AJOUTER UNE PRESTATION
  Tout est dans data.js (SERVICES, PACKS, CATEGORIES…). Vous pouvez le modifier :
  - sur votre ordinateur puis renvoyer le fichier (ou git push),
  - ou directement sur github.com : ouvrez data.js > crayon ✎ > modifiez > « Commit changes ».
  Le site, la page « Services et tarifs » et la fiche tarifs se mettent à jour tout seuls
  (1 à 2 minutes). Pensez à augmenter le numéro ?v= dans les fichiers .html (ex : ?v=42 -> ?v=43)
  pour que les visiteurs voient tout de suite la nouvelle version.

NOM DE DOMAINE (facultatif, ≈ 10 €/an)
  1. Achetez un domaine (ex : itsolution-martinique.fr) chez OVH, Gandi, Hostinger…
  2. GitHub > Settings > Pages > « Custom domain » : tapez votre domaine > Save.
  3. Chez le registraire, créez les enregistrements DNS indiqués par GitHub
     (4 enregistrements A vers 185.199.108.153 / .109.153 / .110.153 / .111.153,
     ou un CNAME vers VOTRE-COMPTE.github.io pour « www »).
  4. Cochez « Enforce HTTPS » quand c'est disponible.

POUR ÊTRE TROUVÉ SUR GOOGLE
  - Fiche Google Business pour chaque agence (Ducos, Le Robert), avec le lien du site.
    Copiez le lien « Demander des avis » dans data.js (CONFIG.avisGoogleUrl).
  - Inscrivez le site sur https://search.google.com/search-console
